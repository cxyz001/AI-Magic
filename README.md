# AI Magic

AI Magic 是一款基于人工智能技术的创意内容生成工具，通过简单的界面让用户能够快速创建图像和视频内容。

## 功能特点

- **文生图**：通过文字描述生成4副图片，可以下载
- **图生视频**：上传图片生成一段视频，可以下载
- **文生视频**：通过文字描述直接生成视频，可以下载

## 使用方法

1. 打开 `AIMagic.html` 文件，启动应用
2. 选择需要使用的功能（文生图、图生视频或文生视频）
3. 根据提示输入文字描述或上传图片
4. 点击生成按钮，等待内容生成
5. 预览生成的内容并下载使用

## 技术说明

此应用是一个演示版本，使用了以下技术：

- HTML5 / CSS3 / JavaScript
- 响应式设计，适应不同屏幕大小
- 模拟 API 服务（在实际应用中，这些应该连接到真实的 AI 服务）

## 注意事项

- 当前版本使用模拟 API，生成的内容为演示用随机图像和视频
- 在实际应用中，需要替换为真实的 AI 服务 API
- 应用需要在网络环境下运行，以加载字体和示例内容
